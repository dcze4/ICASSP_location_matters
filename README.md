# Location Matters — Supplementary Material

Supplementary material for the ICASSP submission _Location Matters: Layer-wise Prompt Conditioning for Voice–Style Disentanglement in TTS_. Full write-up: [`supplementary_material.pdf`](supplementary_material.pdf).

- `supplementary/feature_extraction/` — style and emotion features computed from audio
- `supplementary/scoring_functions/` — annotation scoring, pitch, and discretization
- `supplementary/prompt_templates/` — structured and template prompt generation
- `supplementary/mixedlm_gee/` — MixedLM/GEE script and full reanalysis outputs
